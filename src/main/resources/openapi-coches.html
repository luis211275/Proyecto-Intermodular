API Coches - Documentación

Documentación técnica del módulo de coches para el proyecto intermodular.

Flujo de Compra en el Frontend:
  1. El usuario hace clic en una tarjeta: Llamar a GET /detalle?idCoche=X.
  2. Abrir Modal de Detalle con todos los datos y botón "Comprar".
  3. Clic en "Comprar": Llamar a GET /presupuesto?idCoche=X para mostrar el desglose (IVA, Comisión).
  4. Confirmar compra en el Modal de Contrato: Llamar a POST /comprar.

2. Flujo de Venta y Facturación

GET /apis/facturas/listar?compradorId=5

Lista todas las facturas de un comprador.

[
  {
    "id": 100,
    "compradorId": 5,
    "totalBase": 24500.0,
    "ivaImporte": 5145.0,
    "comisionPlataforma": 735.0,
    "totalPagado": 30380.0,
    "fechaEmision": "2024-04-21T18:30:00Z"
  }
]

GET /apis/facturas/detalle?idFactura=100

Obtiene el detalle de una factura específica.

Response:

{
  "id": 100,
  "compradorId": 5,
  "totalBase": 24500.0,
  "ivaImporte": 5145.0,
  "comisionPlataforma": 735.0,
  "totalPagado": 30380.0,
  "fechaEmision": "2024-04-21T18:30:00Z"
}

GET /apis/coches/presupuesto?idCoche=1

Calcula los importes del contrato de compraventa (IVA 21% y Comisión 3%).

{
  "idCoche": 1,
  "precioBase": 24500.0,
  "iva": 5145.0,
  "comisionPlataforma": 735.0,
  "totalPagado": 30380.0
}

POST /apis/coches/comprar

Finaliza la compra. Registra la factura en BD y cambia el estado a Vendido.

Request Body:

{
  "idCoche": 1,
  "idComprador": 5
}

3. Publicación y Edición

POST /apis/coches/publicarcoche

Crea un anuncio. Envía IDs numéricos para las relaciones.

{
  "anioFabricacion": 2022,
  "kilometraje": 45000,
  "precioVenta": 18000.0,
  "versionId": 3,
  "combustibleId": 1,
  "transmisionId": 2,
  "ciudadId": 5,
  "colorId": 2,
  "etiquetaId": 2,
  "categoriaId": 1,
  "vendedorId": 2
}

DELETE /apis/coches/borrarcoche?idCoche=1

Borrado Funcional (Lógico): No elimina el registro de la base de datos, sino que cambia su estado a Desactivado. El coche dejará de aparecer en las búsquedas públicas.

Response:

{
  "id": 1,
  "estado": "Desactivado",
  "mensaje": "Coche desactivado correctamente"
}

4. Gestión de Errores

Los errores siempre devuelven un JSON con este formato:

{
  "error": "COCHE_NO_ENCONTRADO",
  "message": "No existe un coche con id 999"
}
Backend simplificado - Intermodular DAW. Todas las respuestas son planas para facilitar el manejo en el Frontend.
