API Marketplace de Coches

Documentación del módulo de coches y catálogos

Resumen

Formato

JSON y multipart/form-data

Estados de coche

Disponible, Vendido, Desactivado

Base de datos

PostgreSQL

Módulo documentado

Catálogos, coches y favoritos

Schemas

CocheResponse

Campo Tipo Descripción
idCoche number Identificador del coche.
anioFabricacion number Año de fabricación.
kilometraje number Kilómetros del vehículo.
precioVenta number Precio del anuncio.
estado string Disponible, Vendido o Desactivado.
urlImagen string Ruta de la imagen principal.
marca string Marca del vehículo.
modelo string Modelo del vehículo.
version string Versión comercial.
combustible string Tipo de combustible.
transmision string Tipo de transmisión.
ciudad string Ciudad del anuncio.
color string Color del coche.
etiquetaAmbiental string Etiqueta ambiental.
categoria string Categoría del coche.
vendedorNombre string Nombre completo del vendedor.
vendedorEmail string Email de contacto.
vendedorDni string DNI del vendedor (para contrato).
vendedorTelefono string Teléfono de contacto.
subtotal number Precio base sin impuestos ni comisiones.
iva number IVA (21%) calculado.
comision number Comisión de gestión (2%).
total number Precio final (precioVenta).
fechaPublicacion string Fecha de publicación.
